# Orbit Markdown

An Obsidian plugin that:

- hides `{braces}` in Live Preview except on the active line, where they show in `--text-faint`, and shows the text between them in `--text-muted`;
- shows `Q.` and `A.` at the start of a line in `--text-muted`, in Live Preview and Reading view.

Install with [BRAT](https://github.com/TfTHacker/obsidian42-brat): **Add beta plugin** → `mjknght/orbit-markdown`.
